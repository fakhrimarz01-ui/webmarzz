GOTH STYLING — HTML, CSS, JavaScript

CARA MENJALANKAN
Ekstrak ZIP lalu buka index.html dengan browser. Tidak memerlukan npm.
Untuk pengembangan, buka folder di VS Code dan gunakan Live Server bila tersedia.

FILE
index.html: halaman Portfolio dan galeri
about.html: halaman About dan layanan
contact.html: halaman Contact dan formulir
style.css: seluruh desain dan aturan responsif
script.js: menu ponsel, galeri modal, accordion native dan persiapan pesan
assets/: gambar yang diambil dari area foto pada referensi pengguna

MENGEDIT
Ubah tulisan langsung di HTML. Ubah warna di bagian :root pada style.css.
Ganti gambar di assets/ dengan nama file yang sama, atau ubah src di HTML.
Foto hero memakai foto portfolio agar tidak membawa teks screenshot.
Formulir memvalidasi isian dan menyiapkan pesan yang bisa disalin. Belum mengirim email atau menyimpan data di server. Hubungkan backend/email service sendiri jika diperlukan.
Konten proyek dan layanan adalah contoh yang dapat diganti. Tautan media sosial tidak ditambahkan karena akun asli belum diberikan.
